# ── EXCLUIDO A PROPÓSITO, y por qué ────────────────────────────────────────
# gunicorn            El launcher local usa Flask app.run(), no gunicorn.

#                     en modo SQLite no se usa y no hace falta.
# weasyprint          Import diferido en services/md_to_pdf.py. Arrancar en
#                     Windows exigiría pango/cairo, muy difícil de instalar.
#                     Solo afecta a la función MD→PDF.
# notebooklm-py       Import diferido tras el fix de esta sesión. Pesa
#                     muchísimo (arrastra Playwright + navegadores). Solo hace
#                     falta para las funciones de NotebookLM.
# playwright          Mismo motivo: dependencia de notebooklm-py.
# selenium            scorm_import.py y runner.py, que server.py NO importa.
# gevent / gevent-ws  SÍ están: los necesita routes/novnc_proxy.py para el
#                     login embebido de NotebookLM. Ver la nota al final.

# ── Zona horaria del calendario importado ────────────────────────────────
# routes/calendar.py resuelve Europe/Madrid con zoneinfo. Windows no trae base
# de datos de zonas horarias — no existe /usr/share/zoneinfo — así que sin este
# paquete ZoneInfoNotFoundError y el import de calendario responde 500 con
# "server timezone data missing". Verificado en el equipo del usuario.
#
# En el Mac no hace falta porque el sistema ya lo trae; allí lo que se estaba
# usando era el tzdata de Anaconda, no una dependencia del proyecto. Por eso el
# fallo solo aparece en Windows.
tzdata==2025.2

# ── Login embebido de NotebookLM (noVNC) ────────────────────────────────────
# routes/novnc_proxy.py importa gevent A NIVEL DE MÓDULO. server.py lo envuelve
# en try/except, así que la app arranca igual sin esto — y por eso es una
# trampa: la vista embebida no aparece y no hay ningún error visible, solo una
# ventana que no abre. Son 2 MB y un par de segundos: valen la pena.
#
# Nota: esto solo da el proxy WebSocket. El cliente noVNC además espera los
# estáticos en /opt/novnc, que es una ruta de contenedor y no existe en local.
# En una máquina personal el login embebido seguirá sin funcionar aunque las
# dependencias estén; para eso hace falta el contenedor. Lo que sí arregla es
# que /api/settings/notebooklm/status responda y muestre un error claro en vez
# de comportamiento indefinido.
gevent==25.9.1
gevent-websocket==0.10.1
