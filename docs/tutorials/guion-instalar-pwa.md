# Guión 02: Cómo instalar StudyFlow PWA (Multiplataforma)

Título: "Cómo instalar StudyFlow PWA (Android/iOS/Windows/macOS/Linux)"
Duración: 1:30 – 2:00
Objetivo: Mostrar instalación clara paso a paso para todos los SO.

Escena por escena:
00:00 – 00:10: Intro. Mostrar logo StudyFlow, explicar qué es PWA (app instalable).
00:10 – 00:40: Android (Chrome/Edge). Abrir URL, menú ⋯ → Instalar/Añadir a pantalla inicio, confirmar, mostrar icono.
00:40 – 01:00: iOS (Safari). Compartir → Añadir a pantalla de inicio, guardar.
01:00 – 01:15: Windows/macOS/Linux (Chrome/Edge). Menú → Instalar aplicación, abrir en ventana standalone.
01:15 – 01:30: Mostrar abrir desde icono (modo standalone), ventajas, fin.
