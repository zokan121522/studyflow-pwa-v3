⬇ Descargar StudyFlow para Windows 52 MB · ZIP portable

Windows · pasos

  1. Extrae el ZIP completo con Extraer todo (Extract All): no lo ejecutes desde dentro del ZIP.
  2. Haz doble clic en INICIAR_StudyFlow.bat.
  3. La primera vez tarda 2–3 minutos (instala sus dependencias); después arranca en segundos.
  4. Se abre el navegador en http://127.0.0.1:8477/.
  5. Cierra la ventana para detener StudyFlow. Tus datos quedan en %LOCALAPPDATA%\studyflow.
⬇ Descargar StudyFlow para macOS — · ZIP portable

macOS · pasos

  1. Descomprime el ZIP (doble clic sobre él).
  2. Haz doble clic en StudyFlow.command. Si macOS lo bloquea (Gatekeeper): clic derecho → Abrir → Abrir.
  3. La primera vez tarda 2–3 minutos (instala sus dependencias); después arranca en segundos.
  4. Se abre el navegador en http://127.0.0.1:8477/.
  5. Cierra la ventana o pulsa Ctrl+C para detener StudyFlow. Tus datos quedan en ~/Library/Application Support/studyflow.
⬇ Descargar StudyFlow para Linux — · ZIP portable

Linux · pasos

  1. Descomprime el ZIP (con el gestor de archivos o unzip StudyFlow-linux-*.zip).
  2. En una terminal: bash StudyFlow.sh (o doble clic si el gestor de archivos lo permite).
  3. La primera vez tarda 2–3 minutos (instala sus dependencias); después arranca en segundos.
  4. Se abre el navegador en http://127.0.0.1:8477/.
  5. Cierra la ventana para detener StudyFlow. Tus datos quedan en ~/.local/share/studyflow.

Aviso

Paquete sin firma digital

Windows (SmartScreen) puede mostrar el aviso «Windows protegió tu PC» porque el paquete no está firmado digitalmente.

Elige Más información → Ejecutar de todas formas. Es normal: es un paquete propio, no uno comercial.

Gatekeeper (app sin firmar)

macOS puede decir que no se puede abrir porque viene de un desarrollador no identificado.

Clic derecho sobre StudyFlow.command → Abrir → Abrir. Solo la primera vez.

Ejecución del script

Si la terminal no deja ejecutar el script, dale permisos y lánzalo:

chmod +x StudyFlow.sh y después bash StudyFlow.sh.

Verificación copiable

Comprueba que la descarga no se corrompió. En PowerShell o CMD: 

certutil -hashfile StudyFlow-windows-latest.zip SHA256
