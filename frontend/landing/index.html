Cómo instalar StudyFlow PWA

Instálala en pocos pasos según tu sistema operativo.

Android (Chrome/Edge)

  1. Abre StudyFlow en Chrome o Edge
  2. Toca el menú (⋯) → Instalar app o Añadir a pantalla de inicio
  3. Confirma → aparece el icono
  4. Ábrela desde el icono (modo standalone)

iOS (Safari)

  1. Abre StudyFlow en Safari
  2. Toca el botón Compartir (□↑)
  3. Selecciona Añadir a pantalla de inicio
  4. Guarda → icono en pantalla de inicio

Windows (Chrome/Edge)

  1. Abre StudyFlow en Chrome/Edge
  2. Pulsa Instalar en barra o menú (⋯) → Instalar aplicación
  3. Acepta → ventana independiente
  4. Acceso desde menú Inicio/Escritorio

macOS (Chrome/Edge/Safari)

  1. Abre StudyFlow
  2. Chrome/Edge: menú → Instalar aplicación
  3. Safari: Compartir → Añadir a Dock/Pantalla inicio
  4. Abre como app standalone

Linux (Chrome/Edge)

  1. Abre StudyFlow en Chrome/Edge
  2. Menú (⋯) → Instalar aplicación
  3. Confirma → aparece en lanzador
  4. Ábrela desde lanzador

Actualizaciones PWA

Controladas, no forzadas.

  1. El Service Worker detecta nueva versión → queda en waiting
  2. Aparece banner "Nueva versión disponible – Actualizar" a todos con app instalada
  3. Cada uno acepta cuando quiera
  4. Al pulsar Actualizar, recarga con nueva versión
  5. Multiplataforma (Linux/Win/macOS/iOS/Android)
